In this chapter, you'll learn about physics simulation in Gazebo, the premier robotics simulation environment. Gazebo provides accurate and efficient physics simulation that's essential for testing humanoid robots in virtual environments before deploying them in the real world.

## Introduction to Gazebo Physics

Gazebo uses the Open Dynamics Engine (ODE), Bullet Physics, or Simbody as its underlying physics engine to simulate rigid body dynamics. This allows for realistic simulation of how robots interact with their environment, including collisions, friction, and response to forces.

### Key Physics Concepts in Gazebo

1. **Gravity**: The constant force that affects all objects in the simulation
2. **Collisions**: Detection and response when objects make contact
3. **Dynamics**: How objects move and respond to forces over time
4. **Joints**: Constraints that connect different parts of a robot
5. **Materials**: Surface properties that affect interaction between objects

## Setting Up Physics Parameters

Gazebo worlds are defined in SDF (Simulation Description Format) files that specify the physics parameters for the simulation environment.

### Global Physics Parameters

The global physics parameters define the overall behavior of the physics engine:

```xml
<sdf version="1.7">
  <world name="default">
    <!-- Physics engine configuration -->
    <physics type="ode">
      <max_step_size>0.001</max_step_size>
      <real_time_factor>1.0</real_time_factor>
      <real_time_update_rate>1000.0</real_time_update_rate>
      <gravity>0 0 -9.8</gravity>
    </physics>

    <!-- World content goes here -->
  </world>
</sdf>
```

Key parameters:
- `max_step_size`: The maximum time step for physics integration (smaller values are more accurate but slower)
- `real_time_factor`: The target rate at which simulation time should advance relative to real time
- `real_time_update_rate`: The rate at which physics updates occur
- `gravity`: The gravitational acceleration vector (typically 0 0 -9.8 m/s²)

### Gravity Configuration

Gravity can be adjusted to simulate different environments:

```xml
<gravity>0 0 -1.62</gravity>  <!-- Moon gravity -->
<gravity>0 0 -3.71</gravity>  <!-- Mars gravity -->
<gravity>0 0 0</gravity>      <!-- Zero gravity -->
```

## Collision Detection and Dynamics

Gazebo's collision detection system handles interactions between objects in the simulation environment.

### Collision Properties

Each link in a robot model can have collision properties defined:

```xml
<link name="link_name">
  <collision name="collision">
    <geometry>
      <box>
        <size>1.0 1.0 1.0</size>
      </box>
    </geometry>
    <surface>
      <friction>
        <ode>
          <mu>1.0</mu>
          <mu2>1.0</mu2>
        </ode>
      </friction>
      <bounce>
        <restitution_coefficient>0.1</restitution_coefficient>
        <threshold>100000</threshold>
      </bounce>
      <contact>
        <ode>
          <soft_cfm>0</soft_cfm>
          <soft_erp>0.2</soft_erp>
          <kp>1e+13</kp>
          <kd>1</kd>
          <max_vel>0.01</max_vel>
          <min_depth>0</min_depth>
        </ode>
      </contact>
    </surface>
  </collision>
</link>
```

Key properties:
- `mu` and `mu2`: Friction coefficients for primary and secondary friction directions
- `restitution_coefficient`: Bounciness of collisions (0 = no bounce, 1 = perfectly elastic)
- `soft_cfm` and `soft_erp`: Constraint Force Mixing parameters for soft contacts
- `kp` and `kd`: Spring stiffness and damping coefficients

### Dynamics Properties

Dynamics properties define how objects respond to forces:

```xml
<link name="link_name">
  <inertial>
    <mass>1.0</mass>
    <inertia>
      <ixx>0.1</ixx>
      <ixy>0.0</ixy>
      <ixz>0.0</ixz>
      <iyy>0.1</iyy>
      <iyz>0.0</iyz>
      <izz>0.1</izz>
    </inertia>
  </inertial>
</link>
```

## Environment and World Building

Creating realistic environments is crucial for effective simulation. Gazebo provides tools for building complex worlds with various objects and terrains.

### Basic World Structure

A basic Gazebo world file includes:

```xml
<sdf version="1.7">
  <world name="my_world">
    <!-- Physics engine configuration -->
    <physics type="ode">
      <max_step_size>0.001</max_step_size>
      <real_time_factor>1.0</real_time_factor>
      <gravity>0 0 -9.8</gravity>
    </physics>

    <!-- Include models -->
    <include>
      <uri>model://ground_plane</uri>
    </include>
    <include>
      <uri>model://sun</uri>
    </include>

    <!-- Define static objects -->
    <model name="table">
      <pose>0 0 0 0 0 0</pose>
      <static>true</static>
      <link name="link">
        <collision name="collision">
          <geometry>
            <box>
              <size>1.0 1.0 0.1</size>
            </box>
          </geometry>
        </collision>
        <visual name="visual">
          <geometry>
            <box>
              <size>1.0 1.0 0.1</size>
            </box>
          </geometry>
        </visual>
        <inertial>
          <mass>10.0</mass>
          <inertia>
            <ixx>1.0</ixx>
            <ixy>0.0</ixy>
            <ixz>0.0</ixz>
            <iyy>1.0</iyy>
            <iyz>0.0</iyz>
            <izz>1.0</izz>
          </inertia>
        </inertial>
      </link>
    </model>
  </world>
</sdf>
```

### Terrain and Complex Environments

For more complex environments, you can define terrains:

```xml
<model name="uneven_terrain">
  <link name="link">
    <collision name="collision">
      <geometry>
        <heightmap>
          <uri>file://media/materials/textures/uneven_terrain.png</uri>
          <size>10 10 2</size>
          <pos>0 0 0</pos>
        </heightmap>
      </geometry>
    </collision>
    <visual name="visual">
      <geometry>
        <heightmap>
          <uri>file://media/materials/textures/uneven_terrain.png</uri>
          <size>10 10 2</size>
          <pos>0 0 0</pos>
        </heightmap>
      </geometry>
    </visual>
  </link>
</model>
```

## Practical Examples

### Example 1: Physics-Based Ball Drop

A simple example demonstrating gravity and collision response:

```xml
<sdf version="1.7">
  <world name="ball_drop">
    <physics type="ode">
      <max_step_size>0.001</max_step_size>
      <real_time_factor>1.0</real_time_factor>
      <gravity>0 0 -9.8</gravity>
    </physics>

    <model name="ground_plane">
      <include>
        <uri>model://ground_plane</uri>
      </include>
    </model>

    <model name="falling_ball">
      <pose>0 0 5 0 0 0</pose>
      <link name="link">
        <collision name="collision">
          <geometry>
            <sphere>
              <radius>0.1</radius>
            </sphere>
          </geometry>
        </collision>
        <visual name="visual">
          <geometry>
            <sphere>
              <radius>0.1</radius>
            </sphere>
          </geometry>
        </visual>
        <inertial>
          <mass>0.5</mass>
          <inertia>
            <ixx>0.001</ixx>
            <ixy>0.0</ixy>
            <ixz>0.0</ixz>
```

### Example 2: Robot in Physics Environment

Integrating a robot model with physics simulation:

```xml
<sdf version="1.7">
  <world name="robot_physics">
    <physics type="ode">
      <max_step_size>0.001</max_step_size>
      <real_time_factor>1.0</real_time_factor>

    </physics>

    <model name="ground_plane">
      <include>
        <uri>model://ground_plane</uri>

    </model>

    <!-- Include your robot model -->
    <include>
      <uri>model://my_robot</uri>
```

## Integration with ROS 2

Gazebo integrates seamlessly with ROS 2 through the Gazebo ROS packages, allowing you to control simulated robots with ROS 2 nodes.

### Launching Gazebo with ROS 2

To launch Gazebo with ROS 2 integration:

```xml
<launch>
  <!-- Launch Gazebo -->
  <include file="$(find-pkg-share gazebo_ros)/launch/gazebo.launch.py"/>

  <!-- Spawn your robot in Gazebo -->
  <node pkg="gazebo_ros" exec="spawn_entity.py" name="spawn_robot" output="screen">
    <param name="name" value="my_robot"/>
    <param name="xml" value="$(var robot_description)"/>
    <param name="x" value="0"/>
    <param name="y" value="0"/>
    <param name="z" value="0.5"/>
  </node>
</launch>
```
