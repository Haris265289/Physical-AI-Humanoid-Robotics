# Unity for Robot Visualization

In this chapter, you'll learn how to use Unity for high-fidelity robot visualization and creating compelling human-robot interaction scenes. Unity's powerful rendering capabilities make it ideal for creating realistic visualizations that complement physics-based simulation environments like Gazebo.

## Introduction to Unity for Robotics

Unity is a powerful 3D development platform that excels at creating high-fidelity visualizations. While Gazebo focuses on physics-accurate simulation, Unity focuses on visual fidelity, making it perfect for creating compelling visualizations and human-robot interaction scenarios.

### Unity vs. Gazebo for Robotics

| Aspect | Gazebo | Unity |
|--------|--------|-------|
| Primary Focus | Physics Simulation | Visual Rendering |
| Accuracy | Physics-accurate | Visually-appealing |
| Use Case | Testing algorithms | Visualization, interaction |
| Performance | Real-time physics | Real-time rendering |

Unity can complement Gazebo by providing high-quality visualizations of the same simulation data.

## Setting Up Unity for Robotics

### Unity Robotics Setup

To use Unity for robotics applications, you'll typically need:

1. **Unity Hub**: For managing Unity installations
2. **Unity Editor**: Latest LTS version recommended
3. **Unity Robotics Package**: For ROS integration
4. **Robot Framework**: For creating robot models

### Installing Unity Robotics Package

The Unity Robotics Package provides:
- ROS communication capabilities
- Robot visualization tools
- Sample scenes and examples

To install:
1. Open Unity Package Manager (Window > Package Manager)
2. Click the + button and select "Add package from git URL"
3. Enter: `com.unity.robotics.ros-tcp-connector` for ROS connection
4. Also install: `com.unity.robotics.urdf-importer` for robot model import

### Manual Robot Creation

For more control, you can create robots manually:

```csharp
using UnityEngine;

public class ManualRobotBuilder : MonoBehaviour
{
    [System.Serializable]
    public class JointConfiguration
    {
        public string jointName;
        public JointType jointType;
        public float minAngle;
        public float maxAngle;
        public float maxVelocity;
    }

    [SerializeField] private JointConfiguration[] joints;
    [SerializeField] private Material robotMaterial;

    void Start()
    {
        CreateRobotBase();
        CreateJoints();
    }

    private void CreateRobotBase()
    {
        GameObject baseLink = GameObject.CreatePrimitive(PrimitiveType.Capsule);
        baseLink.name = "base_link";
        baseLink.transform.SetParent(transform);
        baseLink.GetComponent<Renderer>().material = robotMaterial;
    }

    private void CreateJoints()
    {
        foreach (var joint in joints)
        {
            CreateJoint(joint);
        }
    }

    private void CreateJoint(JointConfiguration config)
    {
        GameObject jointGO = new GameObject(config.jointName);
        jointGO.transform.SetParent(transform);

        // Add appropriate joint component based on type
        switch (config.jointType)
        {
            case JointType.Revolute:
                var hinge = jointGO.AddComponent<HingeJoint>();
                hinge.limits = new JointLimits
                {
                    min = config.minAngle,
                    max = config.maxAngle
                };
                hinge.useLimits = true;
                break;
            case JointType.Prismatic:
                var prismatic = jointGO.AddComponent<ConfigurableJoint>();
                // Configure for linear movement
                break;
        }
    }
}
```

## High-Fidelity Rendering Techniques

### Materials and Shaders

Creating realistic robot materials:

```csharp
using UnityEngine;

public class RobotMaterialController : MonoBehaviour
{
    [SerializeField] private Material[] robotMaterials;
    [SerializeField] private PhysicMaterial robotPhysicsMaterial;

    void Start()
    {
        ApplyMaterials();
    }

    private void ApplyMaterials()
    {
        foreach (Renderer renderer in GetComponentsInChildren<Renderer>())
        {
            int materialIndex = Random.Range(0, robotMaterials.Length);
            renderer.material = robotMaterials[materialIndex];

            // Apply physics material to colliders
            if (renderer.GetComponent<Collider>() != null)
            {
                renderer.GetComponent<Collider>().material = robotPhysicsMaterial;
            }
        }
    }

    // Update material properties dynamically
    public void SetRobotColor(Color newColor)
    {
        foreach (Renderer renderer in GetComponentsInChildren<Renderer>())
        {
            renderer.material.color = newColor;
        }
    }
}
```

### Lighting and Environment

Setting up realistic lighting for robot visualization:

```csharp
using UnityEngine;

public class RobotEnvironmentSetup : MonoBehaviour
{
    [SerializeField] private Light mainLight;
    [SerializeField] private Light fillLight;
    [SerializeField] private Light rimLight;

    [SerializeField] private Material[] environmentMaterials;
    [SerializeField] private GameObject[] environmentPrefabs;

    void Start()
    {
        SetupLighting();
        CreateEnvironment();
    }

    private void SetupLighting()
    {
        // Main light (key light)
        mainLight.type = LightType.Directional;
        mainLight.intensity = 1.2f;
        mainLight.color = Color.white;
        mainLight.transform.rotation = Quaternion.Euler(45, 45, 0);

        // Fill light (softer light from opposite side)
        fillLight.type = LightType.Directional;
        fillLight.intensity = 0.3f;
        fillLight.color = Color.gray;
        fillLight.transform.rotation = Quaternion.Euler(45, -135, 0);

        // Rim light (backlight for depth)
        rimLight.type = LightType.Directional;
        rimLight.intensity = 0.5f;
        rimLight.color = new Color(0.8f, 0.9f, 1.0f);
        rimLight.transform.rotation = Quaternion.Euler(45, 225, 0);
    }

    private void CreateEnvironment()
    {
        // Create floor
        GameObject floor = GameObject.CreatePrimitive(PrimitiveType.Plane);
        floor.transform.position = new Vector3(0, -0.5f, 0);
        floor.transform.localScale = Vector3.one * 10;
        floor.GetComponent<Renderer>().material = environmentMaterials[0];

        // Add environment objects
        for (int i = 0; i < 5; i++)
        {
            Vector3 pos = new Vector3(
                Random.Range(-4f, 4f),
                0,
                Random.Range(-4f, 4f)
            );

            int prefabIndex = Random.Range(0, environmentPrefabs.Length);
            Instantiate(environmentPrefabs[prefabIndex], pos, Quaternion.identity);
        }
    }
}
```

## Human-Robot Interaction Scenes

### Creating Interactive Elements

Designing scenes for human-robot interaction:

```csharp
using UnityEngine;
using UnityEngine.Events;

public class HumanRobotInteraction : MonoBehaviour
{
    [System.Serializable]
    public class InteractionEvent
    {
        public string interactionName;
        public UnityEvent onInteraction;
        public float interactionRadius;
        public KeyCode interactionKey;
    }

    [SerializeField] private InteractionEvent[] interactions;
    [SerializeField] private Transform humanCharacter;
    [SerializeField] private Transform robotCharacter;

    void Update()
    {
        HandleInteractions();
    }

    private void HandleInteractions()
    {
        foreach (var interaction in interactions)
        {
            float distance = Vector3.Distance(humanCharacter.position, robotCharacter.position);

            if (distance <= interaction.interactionRadius && Input.GetKeyDown(interaction.interactionKey))
            {
                interaction.onInteraction?.Invoke();
                Debug.Log($"Interaction triggered: {interaction.interactionName}");
            }
        }
    }

    // Visualization for interaction range
    void OnDrawGizmosSelected()
    {
        if (humanCharacter != null)
        {
            Gizmos.color = Color.yellow;
            foreach (var interaction in interactions)
            {
                Gizmos.DrawWireSphere(humanCharacter.position, interaction.interactionRadius);
            }
        }
    }
}
```

### Gesture Recognition Visualization

Creating visual feedback for gesture-based interaction:

```csharp
using UnityEngine;

public class GestureVisualization : MonoBehaviour
{
    [SerializeField] private LineRenderer gestureTrail;
    [SerializeField] private ParticleSystem gestureEffect;
    [SerializeField] private Transform gestureOrigin;

    private Vector3[] gesturePoints;
    private int pointCount = 0;

    void Start()
    {
        InitializeGestureTrail();
    }

    private void InitializeGestureTrail()
    {
        gestureTrail.positionCount = 0;
        gestureTrail.startWidth = 0.1f;
        gestureTrail.endWidth = 0.05f;
        gestureTrail.startColor = Color.blue;
        gestureTrail.endColor = Color.cyan;
        gestureTrail.useWorldSpace = true;
    }

    public void AddGesturePoint(Vector3 point)
    {
        if (pointCount >= gesturePoints.Length)
        {
            // Expand array if needed
            System.Array.Resize(ref gesturePoints, gesturePoints.Length * 2);
        }

        gesturePoints[pointCount] = point;
        gestureTrail.positionCount = pointCount + 1;
        gestureTrail.SetPosition(pointCount, point);
        pointCount++;
    }

    public void CompleteGesture()
    {
        // Play visual effect
        if (gestureEffect != null)
        {
            gestureEffect.Play();
        }

        // Reset for next gesture
        pointCount = 0;
        gestureTrail.positionCount = 0;
    }

    // Clear gesture trail
    public void ClearGesture()
    {
        pointCount = 0;
        gestureTrail.positionCount = 0;
    }
}
```

## Integration with ROS 2

### Unity-Ros Connection

Connecting Unity visualization to ROS 2 systems:

```csharp
using Unity.Robotics.ROSTCPConnector;
using Unity.Robotics.ROSTCPConnector.MessageGeneration;
using UnityEngine;

public class UnityRosBridge : MonoBehaviour
{
    private ROSConnection ros;

    [SerializeField] private string rosIPAddress = "127.0.0.1";
    [SerializeField] private int rosPort = 10000;

    [SerializeField] private Transform robotTransform;
    [SerializeField] private Transform[] jointTransforms;

    void Start()
    {
        ros = ROSConnection.instance;
        ros.Initialize(rosIPAddress, rosPort);

        // Subscribe to robot state topics
        ros.Subscribe<sensor_msgs.JointState>("/joint_states", JointStateCallback);
        ros.Subscribe<geometry_msgs.Pose>("/robot_pose", RobotPoseCallback);
    }

    private void JointStateCallback(sensor_msgs.JointState jointState)
    {
        // Update robot joint positions in Unity
        for (int i = 0; i < jointState.name.Count && i < jointTransforms.Length; i++)
        {
            string jointName = jointState.name[i];
            float jointPosition = jointState.position[i];

            // Apply position to corresponding joint transform
            UpdateJoint(jointName, jointPosition);
        }
    }

    private void RobotPoseCallback(geometry_msgs.Pose pose)
    {
        // Update robot position and orientation
        robotTransform.position = new Vector3(pose.position.x, pose.position.z, pose.position.y);
        robotTransform.rotation = new Quaternion(
            pose.orientation.x,
            pose.orientation.z,
            pose.orientation.y,
            pose.orientation.w
        );
    }

    private void UpdateJoint(string jointName, float position)
    {
        // Find the corresponding joint transform and update it
        foreach (Transform joint in jointTransforms)
        {
            if (joint.name == jointName)
            {
                // Apply position based on joint type
                // For revolute joints, this would be rotation
                joint.localEulerAngles = new Vector3(0, position * Mathf.Rad2Deg, 0);
                break;
            }
        }
    }

    // Publish robot commands to ROS
    public void SendRobotCommand(string commandTopic, object command)
    {
        ros.Send<sensor_msgs.JointState>(commandTopic, (sensor_msgs.JointState)command);
    }
}
```

### Synchronized Visualization

Creating synchronized visualization between Gazebo simulation and Unity:

```csharp
using UnityEngine;
using System.Collections.Generic;

public class SynchronizedVisualization : MonoBehaviour
{
    [System.Serializable]
    public class RobotSyncConfig
    {
        public string robotName;
        public Transform robotModel;
        public List<JointSyncConfig> joints;
    }

    [System.Serializable]
    public class JointSyncConfig
    {
        public string jointName;
        public Transform jointTransform;
        public float positionScale = 1.0f;
        public float velocityScale = 1.0f;
    }

    [SerializeField] private RobotSyncConfig[] robotConfigs;
    [SerializeField] private float syncRate = 60.0f; // Hz

    private float lastSyncTime;

    void Start()
    {
        lastSyncTime = Time.time;
    }

    void Update()
    {
        if (Time.time - lastSyncTime >= 1.0f / syncRate)
        {
            SyncRobotStates();
            lastSyncTime = Time.time;
        }
    }

    private void SyncRobotStates()
    {
        // This would be called with actual robot state data from ROS
        foreach (var robotConfig in robotConfigs)
        {
            SyncRobot(robotConfig);
        }
    }

    private void SyncRobot(RobotSyncConfig config)
    {
        // In a real implementation, this would receive actual robot state data
        // For now, we'll simulate some movement

        // Example: move robot in a circle
        float time = Time.time;
        config.robotModel.position = new Vector3(
            Mathf.Sin(time * 0.5f) * 2.0f,
            0,
            Mathf.Cos(time * 0.5f) * 2.0f
        );

        // Example: animate joints
        foreach (var joint in config.joints)
        {
            float jointAngle = Mathf.Sin(time * 2.0f + joint.GetHashCode()) * 30.0f;
            joint.jointTransform.localEulerAngles = new Vector3(0, jointAngle, 0);
        }
    }

    // Method to update from external data source
    public void UpdateRobotState(string robotName, Dictionary<string, float> jointPositions)
    {
        var robotConfig = System.Array.Find(robotConfigs, r => r.robotName == robotName);
        if (robotConfig != null)
        {
            foreach (var joint in robotConfig.joints)
            {
                if (jointPositions.ContainsKey(joint.jointName))
                {
                    float position = jointPositions[joint.jointName] * joint.positionScale;
                    joint.jointTransform.localEulerAngles = new Vector3(0, position * Mathf.Rad2Deg, 0);
                }
            }
        }
    }
}
```

## Complete Example: Human-Robot Collaboration Scene

Here's a complete example of a human-robot collaboration scene:

```csharp
using UnityEngine;
using UnityEngine.AI;

public class HumanRobotCollaboration : MonoBehaviour
{
    [Header("Characters")]
    [SerializeField] private GameObject humanCharacter;
    [SerializeField] private GameObject robotCharacter;

    [Header("Interaction Points")]
    [SerializeField] private Transform[] workStations;
    [SerializeField] private Transform[] toolStations;
    [SerializeField] private Transform[] storageAreas;

    [Header("Objects")]
    [SerializeField] private GameObject[] workPieces;
    [SerializeField] private Material[] pieceMaterials;

    [Header("UI")]
    [SerializeField] private Canvas interactionCanvas;
    [SerializeField] private UnityEngine.UI.Text statusText;

    private NavMeshAgent humanAgent;
    private NavMeshAgent robotAgent;
    private int currentTask = 0;
    private bool taskActive = false;

    void Start()
    {
        InitializeAgents();
        SetupEnvironment();
        StartCollaborationTask();
    }

    private void InitializeAgents()
    {
        humanAgent = humanCharacter.GetComponent<NavMeshAgent>();
        robotAgent = robotCharacter.GetComponent<NavMeshAgent>();

        if (humanAgent == null) humanAgent = humanCharacter.AddComponent<NavMeshAgent>();
        if (robotAgent == null) robotAgent = robotCharacter.AddComponent<NavMeshAgent>();

        // Configure agent properties
        humanAgent.speed = 2.0f;
        robotAgent.speed = 1.5f;
        humanAgent.angularSpeed = 120f;
        robotAgent.angularSpeed = 90f;
    }

    private void SetupEnvironment()
    {
        // Create work pieces at random positions
        for (int i = 0; i < workPieces.Length; i++)
        {
            Vector3 spawnPos = workStations[Random.Range(0, workStations.Length)].position;
            spawnPos += new Vector3(Random.Range(-0.5f, 0.5f), 0, Random.Range(-0.5f, 0.5f));

            GameObject piece = Instantiate(workPieces[Random.Range(0, workPieces.Length)], spawnPos, Quaternion.identity);
            Renderer pieceRenderer = piece.GetComponent<Renderer>();
            if (pieceRenderer != null)
            {
                pieceRenderer.material = pieceMaterials[Random.Range(0, pieceMaterials.Length)];
            }
        }
    }

    private void StartCollaborationTask()
    {
        if (currentTask < workStations.Length)
        {
            Transform targetStation = workStations[currentTask];

            // Send human to station
            humanAgent.SetDestination(targetStation.position);

            // Send robot to assist
            Vector3 robotPos = targetStation.position + new Vector3(1.5f, 0, 0);
            robotAgent.SetDestination(robotPos);

            statusText.text = $"Task {currentTask + 1}: Human and robot collaborating at workstation";
            taskActive = true;
        }
    }

    void Update()
    {
        if (taskActive)
        {
            CheckTaskCompletion();
        }
    }

    private void CheckTaskCompletion()
    {
        // Check if both agents are near their destinations
        float humanDistance = Vector3.Distance(humanCharacter.transform.position, workStations[currentTask].position);
        float robotDistance = Vector3.Distance(robotCharacter.transform.position,
            workStations[currentTask].position + new Vector3(1.5f, 0, 0));

        if (humanDistance < 0.5f && robotDistance < 0.5f)
        {
            // Task completed, move to next
            CompleteTask();
        }
    }

    private void CompleteTask()
    {
        taskActive = false;
        currentTask++;

        if (currentTask < workStations.Length)
        {
            Invoke("StartCollaborationTask", 2.0f); // Start next task after delay
        }
        else
        {
            statusText.text = "All collaboration tasks completed!";
        }
    }

    // Visualization for debugging
    void OnDrawGizmos()
    {
        if (workStations != null)
        {
            foreach (var station in workStations)
            {
                Gizmos.color = Color.blue;
                Gizmos.DrawWireSphere(station.position, 0.5f);
            }
        }
    }
}
```
